Pumpkin Catch — the starter game

This picture is the game running on the PC, not on the console. It's the same game.c that will run on the ESP32 — so if it works here, it works there.

How Kai changes it

  1. Say what you want in Slack #kai_code — "make the pumpkins faster", "add a bomb you must dodge".
  2. Bugsy edits game/game.c (the only file that matters).
  3. bash game/test.sh plays it with fake button presses and checks the rules still hold.
  4. A new screenshot gets posted back to the thread.
  5. When it's good, it gets flashed to the console.

The whole point: nothing broken ever reaches the device.
