🚢 Build the Wi‑Fi airboat yourself: start here

About $60 of parts, no soldering, a phone as the remote. A grown‑up and a kid can build it over a few evenings. Every page below is the real one we used.

  1. The idea: why an airboat (nothing underwater can leak) and how it's judged.
  2. Buy the parts: every part, the price we paid, and what you can skip.
  3. Build the hull: plastic bottles, a plastic sign, zip ties.
  4. Wire it, one step per page: LEGO‑style, every hole labelled. Print it.
  5. Put the code on the chip: one file, boat.ino. After the first time, updates go over Wi‑Fi.
  6. Drive it: try the steering page right now in the simulator, then on the real boat from your phone.
  7. See how we asked the AI: all the messages we sent, word for word, mistakes included.

Made with Claude Code running Claude Opus 5.5 (Anthropic). We talked to it from Slack as "Bugsy"; it wrote the code, the web pages and the wiring drawings, and tested them before we trusted them.

How every project gets built

  1. Say it in words. Goal, what we have, the limits, and how we'll check it worked.
  2. AI drafts it — the web page, the 3D shape, the parts list, the chip's code.
  3. Test before trusting. A robot plays the game, a browser drives the page, a test strip gets printed.
  4. Look at the real thing. The chip's printed labels beat any drawing; the box beats the listing photo.
  5. Flash it — over USB the first time, then over Wi‑Fi.

Add your own page
