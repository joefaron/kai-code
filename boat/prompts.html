How we built this with AI

Every message we sent to the AI, word for word (a few private details removed), in order — typos and all. Nothing here was written by a programmer. If you copy these messages into your own AI coding assistant, you can build the same thing.

How it works

  • The AI is Claude Code, running on a home computer. It can read and write files, run programs, search the web and drive a web browser — not just chat.
  • We talk to it in Slack, in a channel called #boat. Type a message, it does the work, it replies in the thread.
  • Its folder is live on the internet. The files it writes on the home computer are this website, so a change shows up at the boat site the moment it's saved.
  • Want to do it without that setup? Any AI coding tool can write the same files. To put them online for free, drag the folder onto Netlify Drop, or push it to GitHub Pages. (Those host plain HTML; this site uses a little PHP, so ask the AI to convert it to plain HTML first — that is a one-message job.)
  • The prompts are messy on purpose. Most were spoken into a phone. You do not need to write perfectly. You need to say what you want, test what you get, and say what is wrong with it.

💡 What we learned about working with AI

Test it yourself. The first steering was wrong, and the AI didn't know until a human drove it. Ask it to attack its own work. "Adversary review the cart" found two mistakes that would have wrecked the boat. Tell it what you already have. A power bank from an old kit cut the cost in half. Make it show the numbers. "Will it tip over?" got a calculation, and then a real test to prove it.
