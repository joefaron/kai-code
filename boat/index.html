The plan in one sentence

Build a recycled-hull airboat — two propellers in the air, nothing spinning underwater — driven by an ESP32 that makes its own Wi‑Fi so a tablet on the sand can steer it with no internet at all.

🔧 Build your own

Everything is free and open source: github.com/joefaron/kai-code. Go in this order: Parts → Design → Build Steps → Wiring → the chip's code → Control (has a simulator: try it now). Curious how we asked the AI? AI Prompts.

📍 Where

A calm, sheltered beach with almost no surf. Flat water = an airboat works great and a light hull won't get flipped by a shorebreak.

📅 When

This fall. Three 55‑minute class periods + home build time.

🏆 How it's judged

Best design · most creative · best use of recycled materials · best engineering solution · finishing position in the race.

The teacher's criteria — and how we hit each one

CriteriaOur answer
Must float independentlyClosed-cell foam + sealed bottles in the hull: it floats even if it fills with water
Must move through the waterTwo air propellers (differential thrust — spin one faster to turn, like a tank)
Homemade, not a purchased toyHull is cut and built by Kai and a friend; the electronics are components he wires himself, not an RC boat out of a box
Household / recycled materialsCorrugated plastic sign or 2L bottles + foam board hull, bamboo skewers, hot glue
Nothing left in the oceanZero submerged parts. No shaft seal to leak, no motor to flood, no oil. Electronics ride in a screw-top food container above deck, leashed with fishing line as a backup
Explain the designThis site is the explanation — see Design
Test and improve before the beachPool / bathtub trials logged on the Build Log

⚠️ The honest risk

Electronics + saltwater is the #1 way this project dies on the sand. That is exactly why the design puts nothing underwater and treats the battery box as the only thing that must stay dry. The fallback is built in too: if the electronics fail at the beach, the same hull still floats and can be sail- or balloon-powered for the race. The boat should never depend on the code working.
