🧩 3D-printed parts

These parts are written as code in OpenSCAD: the file describes the shape with numbers. Change bore_motor = 1.9; to 1.8, render, print. Drag a part to spin it.

The prompt that made the coupler

"Design a coupler that joins a 2 mm motor shaft to a 2 mm steel prop rod. It should print standing up with no supports, and be a tight press fit, no glue. Give me the OpenSCAD file."

Version 1 had 2.2 mm holes and the shafts slid straight through. Version 2 uses 1.9 mm, and the fit-test strip checks 1.7–2.1 mm before printing the real part.

Spiral shaft coupler

Joins the 2 mm motor shaft to the 2 mm prop rod. Holes are 1.9 mm so the shafts jam in: no glue.

download .stl · source 3d/shaft_coupler.scad

Hole fit-test strip

Holes from 1.7 to 2.1 mm. Print this first (5 minutes) and see which hole grips your shaft.
