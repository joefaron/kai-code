🎬 You can build anything. You + AI.

A 25-minute talk for a 5th-grade class that has never had robotics. One idea per slide: engineers learn by testing (and failing), how to talk to AI, and five real jobs it did on Kai's boat — 3D designer, parts expert, architect, electrical engineer, game developer.

▶ Start the slideshow Presenter notes + timer Detailed version (grades 6–8)

Presenting it

  • → / space / clicker = next, ← = back
  • F full screen
  • P opens the presenter window: what to say, what's next, and a timer that turns orange when you're behind. It moves the main screen too.
  • Ctrl+P prints a handout with the speaker notes
  • Bring the boat: slide 10 has the class press LASERS on the real driving app.

The 25 minutes

  1. Try, fail, learn: SpaceX + our 3 boats (5 min)
  2. What AI is, and how to talk to it: what, details, rules, check (4½)
  3. 5 jobs: 3D designer, parts expert, architect, electrical engineer, game developer (11)
  4. Every kind of engineer, safety, write your own message (8)
